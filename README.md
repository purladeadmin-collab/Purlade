# Pūrlāde

Viss amatiermākslas kolektīvam vienuviet — datora programma tautas deju kolektīvam
(Tērpu, Deju, Kopas, Notikumu, Cītības un Zelta pūrs).

## Uzstādīšana (Windows)

Lejupielādē **[Purlade-instaletajs.exe](https://github.com/purladeadmin-collab/purlade/raw/main/Purlade-instaletajs.exe)** un palaid to.
Instalētājs pats lejupielādē jaunāko Pūrlādi (šobrīd v0.7) un tai vajadzīgo Python, uzstāda tos mapē
`%LOCALAPPDATA%\Pūrlāde` un uz darbvirsmas izveido saīsni „Pūrlāde”. Administratora tiesības nav vajadzīgas.
Atinstalēšana: Iestatījumi → Programmas un līdzekļi → Pūrlāde.

Ja Windows parāda „Windows aizsargāja jūsu datoru”, spied **Vairāk informācijas → Tomēr palaist**.
